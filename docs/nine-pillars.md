# The 9 Pillars of Rivet

1. Compile-Time IoC (Zero-lookup DI)
2. Multi-Service Architecture (Monolith to Microservices via config)
3. Polyglot Frontend Support (Vite, Rsbuild, Next.js auto-detected)
4. Persistent Context Engine (SQLite + LanceDB for AI sessions)
5. Story-to-Code Traceability (Endpoints mapped to Jira/Linear stories)
6. The MQI (Matt Quality Index) (Audits complexity, coverage, mutants)
7. The Gauntlet (Strict linters blocking bad code)
8. WASM & Mobile SDK Export
9. The Super-CLI (Slash-commands for agents)
